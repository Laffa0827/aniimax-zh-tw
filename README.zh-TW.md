# Aniimo 家園計算器｜繁體中文版

這是 [Aniimax](https://github.com/ae-bii/aniimax) 的繁體中文玩家版介面。

## 目前狀態

- 保留原 Aniimax 的 Rust / WASM 最佳化核心與 HiGHS Solver。
- 內部設施、物品與配方 ID 維持英文，避免破壞原有計算、儲存設定與分享連結。
- Web UI、設施、物品、能力、個性、環境與主要結果介面改為繁體中文。
- 保留原本的分享設定、瀏覽器儲存、Aniimo 配置與家園配置功能。

## 本地測試

需要 Rust、wasm-pack 與 Node.js。

```bash
./build-wasm.sh
cd web
python3 -m http.server 8080
```

然後開啟 `http://localhost:8080`。

## 開發原則

中文化只處理「顯示層」，不要把遊戲資料的內部 ID 翻成中文。例如 `Farmland` 仍然是內部 ID，但畫面顯示為「田地」。這樣可以最大程度保持與原版資料及計算核心相容。

這是非官方玩家製作工具，與 Aniimo 製作團隊沒有隸屬、合作或官方認可關係。部分遊戲資料可能尚未在遊戲內完全確認，計算器會在相關位置標示。

## 繁體中文版目前功能

- 主要介面、說明、計算原理與結果顯示繁體中文化
- 遊戲設施、物品、能力、個性與環境名稱提供繁中顯示層；內部 ID 維持原版
- 保留原版 Rust / WASM / HiGHS 最佳化核心
- 家園設定會自動儲存在瀏覽器
- 可建立多個「家園設定檔」，在同一台裝置上保存不同家園方案並快速切換
- 原有分享連結功能保持不變


## 繁體中文版本

本版本以原版 Aniimax 的計算核心與遊戲資料為基礎，主要提供繁體中文介面與中文使用說明；不新增原版沒有的遊戲規則或電力計算系統。
